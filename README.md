# data-manager-platform

ノーコードデータ管理プラットフォーム

**ブラウザだけで使えるノーコードアプリ作成基盤**

## 特徴

- JSON定義ファイル（columns.json）を書くと自動でアプリが構築
- apps.jsonで複数アプリ切替
- GUIエディタでcolumns.jsonを編集・追加・並び替え
- CSVエクスポート / JSONバックアップ・復元
- ボタン名、テーマ（色）もJSONで制御
- 完全ノーコード運用
- GitHub Pagesで公開可

## 使い方

1. `apps.json`にアプリ一覧を記載
2. `products.json`や`todo.json`のようにcolumns.jsonを作成
3. index.htmlを開く（またはGitHub Pagesに公開）
